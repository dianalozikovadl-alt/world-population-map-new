# World People Map — самостоятельный проект

Новый независимый сайт. Старый проект не используется и не изменяется.

## Подключено

- Supabase как общая база данных.
- Таблица `participants`.
- Общая карта участников.
- Общая статистика для всех посетителей.
- Пол: Мужской / Женский.
- Должность: 6 категорий.
- Возраст и свободный ввод должности отсутствуют.

## Публикация на Vercel

1. Создайте новый GitHub repository.
2. Загрузите все файлы этого проекта.
3. В Vercel выберите **Add New → Project**.
4. Импортируйте новый GitHub repository.
5. Для обычного статического проекта Build Command можно оставить пустым.
6. Deploy.

Supabase URL и publishable key уже находятся в `app.js`. Publishable/anon key предназначен для клиентского приложения; секретные ключи в проект не добавлялись.

## Supabase

В базе должна существовать таблица `public.participants` с RLS и политиками SELECT/INSERT, которые были созданы ранее.

Важно: сейчас сайт не имеет авторизации. Любой посетитель может добавить участника. Это соответствует текущей концепции формы. Если потребуется защита от спама/дубликатов, следующим этапом можно добавить CAPTCHA, rate limiting или авторизацию.
